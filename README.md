# eCommerce-Data-Analysis-and-ML

Project Overview:
This project focuses on leveraging machine learning to analyze eCommerce data and predict factors influencing purchases on an eCommerce website. The project involves exploring and merging large datasets to identify key features that drive consumer behavior and enhance the online shopping experience.

Key Features:
Machine Learning Models: Implemented and fine-tuned several machine learning models, including Gradient Boosting, Random Forest, and Logistic Regression, to predict purchase behavior.
Data Enrichment: Merged a 6 GB eCommerce dataset with an additional 1 GB of company-specific data to improve feature richness and accuracy of predictions.
Exploratory Data Analysis (EDA): Conducted detailed analysis of the dataset to uncover patterns, correlations, and potential factors influencing customer purchase decisions.
Feature Engineering: Applied strategic feature engineering to transform raw data into meaningful features for better model performance.
